What it does

slideshow turns a folder of photos into an MP4 slideshow with ffmpeg. Ken Burns pan and zoom, crossfades, an optional title card and optional music. It is one Python file with no dependencies.

  • Gives every photo a slow Ken Burns move with zoompan: zoom-in, zoom-out, pan, none, or random (the default, which never repeats the same move twice in a row).
  • Joins the photos with xfade crossfades: fade, slideleft, circleopen, or none for hard cuts.
  • Outputs 1080p (1920x1080), 720p (1280x720), vertical (1080x1920) or square (1080x1080). Photos that do not match the frame are shown over a blurred copy of themselves (the default), on black bars or cropped to fill.
  • Adds an optional title card, drawn with a small built-in pixel font, so it works even when your ffmpeg has no drawtext.
  • Adds optional music, cut to the length of the video, looped if it is shorter, and faded out at the end.
  • Sorts by name (natural order, so img2 comes before img10) or by the EXIF date inside JPEGs.
  • Keeps memory down by rendering one photo at a time and joining the clips in small batches instead of building one giant filter graph.
  • Runs on your machine. Nothing is uploaded.

Install

You need Python 3.8 or newer and ffmpeg (with ffprobe) on your PATH. There are no Python packages to install.

# ffmpeg
brew install ffmpeg            # macOS
sudo apt install ffmpeg        # Debian, Ubuntu
winget install ffmpeg          # Windows

# slideshow
pipx install git+https://github.com/0xnirlin/photo-slideshow-maker

Or skip the install. The tool is the single file slideshow.py. Clone the repo and run it directly:

git clone https://github.com/0xnirlin/photo-slideshow-maker
cd photo-slideshow-maker
./slideshow photos/
python3 slideshow.py photos/

Usage examples

1. Every photo in a folder

3 seconds each, random motion, fade, 1080p.

slideshow photos/

2. Pick the photos yourself, in your order

slideshow cover.jpg a.jpg b.jpg c.jpg -o trip.mp4

3. Zoom in on every photo and slide between them

slideshow photos/ --seconds 5 --motion zoom-in --transition slideleft

4. A vertical video, cropped to fill

slideshow photos/ --size vertical --fit crop

5. A title card, then music that fades out

slideshow photos/ --title "Summer in Lisbon" --music song.mp3

To see the order and the length without rendering anything, add --dry-run. Real output from slideshow photos/ --size 720p on three photos:

How long will it be, and what does it cost?

The length is:

length = (photos x seconds) + title seconds - (slides - 1) x transition seconds

Slides is the number of photos, plus one if you add a title. Each photo gets --seconds of screen time and every join eats --transition-seconds from that. With --transition none there is no overlap, so it is just photos x seconds. Seconds are rounded to whole frames, so at 30 fps the real length can differ from the formula by a frame or two.

CommandMathMeasured
3 photos, --seconds 3, default fade 0.83 x 3 - 2 x 0.87.40 s
3 photos, --seconds 3, 3 s title, fade 0.83 x 3 + 3 - 3 x 0.89.60 s
12 photos, --seconds 3, fade 0.812 x 3 - 11 x 0.827.20 s

Memory and speed, measured on an Apple M2 Mac with ffmpeg 8.0.1, with the largest ffmpeg process as reported by /usr/bin/time -l:

RunWall timePeak memory
3 photos, --size 720p5.4 s537 MB
3 photos, 1080p, title and music, default batch15.4 s881 MB
12 photos, hidden 160x90 test size, --batch 41.7 s93 MB

The photos in these runs were 320x180 PNGs scaled up to the output size, so they say little about how long real 12 megapixel photos take to decode. If memory is tight, use --size 720p, --batch 2 and --threads 1.

Each photo is rendered alone into a short clip, then the clips are joined with xfade a few at a time, and the results are joined again. A 12 photo set never needs one filter graph with 12 inputs.

FAQ

Which photo formats work?

JPEG, PNG, WebP, BMP and TIFF. Whatever your ffmpeg can decode from those extensions.

Why can't the transition be longer?

The overlap can be at most half of --seconds. Otherwise one photo would be fading in and out at the same time. The tool tells you if you go over.

Does --seconds include the crossfade?

Yes. A photo is on screen for --seconds in total, and the first and last --transition-seconds of that are shared with its neighbours.

What if my music is shorter than the slideshow?

It loops. If it is longer, it is cut at the end of the video. The fade-out is applied to the end either way, and --music-fade 0 turns it off.

Why does the title look blocky?

It uses a tiny built-in 5x7 pixel font so it works with any ffmpeg build, including ones without drawtext. It draws capital letters, digits and basic punctuation, and accents are stripped. For a designed title, make a PNG in any editor and put it first in the list.

Do portrait photos get rotated correctly?

Portrait photos made as portrait pixel data work (tested). Photos that rely on an EXIF rotation flag depend on what your ffmpeg version does with that flag. This tool does not read or apply it itself, and it was not tested.

Can I mix portrait and landscape photos?

Yes. --fit blur (the default) and --fit contain keep each photo whole, --fit crop fills the frame and cuts the edges.

The file is too big.

Raise --crf (for example 23), use --preset slow, pick --size 720p, or lower --fps.

It says ffmpeg is not found.

Install ffmpeg (see Install) and open a new terminal so the PATH updates. Check with ffmpeg -version and ffprobe -version.

Which Python?

3.8 or newer. There are no third-party packages.
